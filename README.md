# Nauka japońskiego

Kurs japońskiego od zera: wymowa, hiragana i katakana, lekcje od N5 do N1 i PRO, czytanki, słówka, kanji i ćwiczenia z głosem.

**Otwórz:** https://kardapan-alt.github.io/japonski/

Na telefonie dodaj stronę do ekranu głównego, wtedy działa jak aplikacja, także bez internetu:
- iPhone (Safari): Udostępnij → Do ekranu początkowego
- Android (Chrome): menu ⋮ → Zainstaluj aplikację

Postępy zapisują się w telefonie. Między urządzeniami przeniesiesz je „Kodem postępów” w Ustawieniach.
